# calcEngine

Here is a java project to do some math calculation by simulating a calculator. It demonstrates the use of various object-oriented programming principles, including inheritance, polymorphism, and exception handling. The engine supports basic arithmetic operations and allows for dynamic processing of calculation commands.

## Features
 - Basic Arithmetic Operations: Addition, Subtraction, Multiplication, Division
 - Power Calculation: Raise a number to the power of another number
 - Dynamic Command Processing: Process calculation commands from strings
 - Exception Handling: Handle invalid commands and input gracefully

## Classes Overview
 - Main: Entry point of the application. Demonstrates the usage of various components of the CalcEngine.
 - MathEquation: Represents a mathematical equation and supports execution of basic operations.
 - CalculateBase: Abstract base class for different types of calculations (Adder, Subtracter, Multiplier, Divider).
 - DynamicHelper: Processes dynamic calculation commands.
 - CalculateHelper: Parses and processes string commands for calculations.
 - Adder: Performs addition.
 - Subtracter: Performs subtraction.
 - Multiplier: Performs multiplication.
 - Divider: Performs division.
 - PowerOf: Performs exponentiation.
 - InvalidStatementException: Custom exception for invalid calculation commands.

## How to Run
1. Ensure you have Java installed on your system.
2. Clone or download the repository.
3. Compile the Java files.
4. Run the Main class.
